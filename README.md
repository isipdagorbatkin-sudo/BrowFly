# Telegram Mini App для записи к Юлии

Рабочий каркас мини-приложения и Telegram-бота для записи на ресницы/брови.

## Запуск

1. Установить зависимости:

```bash
npm install
```

2. Создать `.env` из `.env.example` и вставить токен бота:

```bash
copy .env.example .env
```

3. Запустить:

```bash
npm run dev
```

Mini App: http://localhost:5173  
API: http://localhost:3001

## Telegram

В BotFather у бота нужно указать Web App URL. Для локального теста через Telegram понадобится публичный HTTPS-туннель, например ngrok, и значение `PUBLIC_WEBAPP_URL`.

http://localhost:5173/?admin=1

## Что есть

- публичный профиль мастера;
- настраиваемые соцсети, адрес, описание, фото;
- категории услуг и подуслуги с фото, ценой и длительностью;
- выбор услуги, календарь и доступные слоты;
- блокировка дней/времени в расписании админом;
- записи и список заявок в админке;
- отзывы со звездами;
- напоминание пользователю за 3 часа через Telegram-бота.
